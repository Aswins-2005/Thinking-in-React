# React Product Search & Filter

A simple and interactive product search and filtering application built using **React.js**.

## 🚀 Features

- Display products in a structured table.
- Separate products into Fruits and Vegetables categories.
- Search products by name.
- Filter products based on stock availability.
- Dynamically update the product list using React state.
- Reusable React components.

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite

## ⚙️ Installation & Setup

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd YOUR_PROJECT_FOLDER
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```
